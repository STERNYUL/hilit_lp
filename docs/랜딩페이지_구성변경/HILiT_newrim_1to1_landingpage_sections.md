# 전체 핵심 메시지

## Main Message

**한 번의 경기, 모두의 하이라이트.**

HILiT은 여러 사람이 함께 나온 스포츠 영상에서  
**원하는 사람을 찾고, 움직임을 추적하고, AI 에이전트가 하이라이트 숏폼 제작까지 이어주는 스포츠 미디어 플랫폼**입니다.

한 경기 영상이 한 사람의 영상으로 끝나는 것이 아니라,  
**1개의 팀 영상을 N명의 개인 콘텐츠로 전환**하고,  
개인의 기록이 다시 팀·시설·대회의 홍보 콘텐츠로 확장되는 구조를 지향합니다.

한 번의 경기 영상 안에는 여러 명이 등장하지만  
실제로 콘텐츠를 만드는 사람은 일부에 그칩니다.

### 꾸준히 기록하기 어렵습니다
편집이 번거로우면 다음 경기에서도  
“일단 찍기만 하고 나중에 해야지”가 반복됩니다.

# TO-BE 03-A — TEAM / 동아리·동호회

## TITLE

### 팀원들의 기록이 쌓이면
### 하나의 팀 이야기가 됩니다

공동 촬영한 한 경기 영상을  
팀원별 개인 하이라이트로 전환합니다.

각 팀원이 자신의 영상을 기록하고 공유하면  
콘텐츠가 특정 에이스 선수나 편집을 잘하는 일부 사람에게만 집중되지 않습니다.

### 팀에게 생기는 가치

- 팀원별 개인 하이라이트
- 경기별 팀 기록 축적
- 활동의 역사를 보여주는 팀 페이지
- 구성원의 소속감 강화
- SNS에 지속적으로 사용할 콘텐츠 확보
- 팀을 처음 보는 사람에게 활동 분위기 전달
- 신규 멤버 모집용 콘텐츠 자산 확보

### Promotion Effect

**기존**

팀 운영진 한 명이  
사진과 영상을 모아  
직접 편집하고 게시

↓

**HILiT**

경기 1회 촬영  
→ 팀원별 콘텐츠 생성  
→ 각자의 채널에서 공유  
→ 팀 노출 접점 증가  
→ 팀 페이지 방문  
→ 신규 멤버 관심/유입

> **운동이 사람을 모으고, 기록이 팀을 성장시킵니다.**

# TO-BE 03-B — 대관 사업자 / 체육시설

## TITLE

### 회원의 운동 기록이
### 시설의 홍보 콘텐츠가 됩니다

체육관·풋살장 등 대관 사업자에게  
이용자의 운동 영상은 단순한 경기 기록을 넘어  
**시설에서 실제로 어떤 활동이 일어나고 있는지를 보여주는 콘텐츠**가 될 수 있습니다.

HILiT은 시설에서 촬영된 운동 영상을  
개인의 기록과 시설의 홍보 접점으로 연결하는 구조를 지향합니다.

### 시설에게 생기는 가치

- 회원에게 개인 운동 기록 제공
- 회원 경험 차별화
- 경기/활동 콘텐츠의 반복 생산
- 실제 이용 장면 기반의 홍보 소재 확보
- 시설 SNS 운영 소재 확보
- 팀·동호회 콘텐츠를 통한 자연스러운 시설 노출
- 기존 팀의 재방문 접점 강화
- 새로운 팀/회원 유입 가능성 검증

### Promotion Loop

`시설에서 경기 진행`

→ `하나의 원본 영상 촬영`

→ `참여자별 하이라이트 생성`

→ `참여자가 자신의 콘텐츠 공유`

→ `영상 속 시설이 반복 노출`

→ `시설/팀 페이지 발견`

→ `새로운 이용자의 관심`

# TO-BE 03-C — 대회 주최자 / 리그·협회

## TITLE

### 한 경기가
### 참가자 모두의 대회 콘텐츠가 됩니다

대회 주최자는 경기 영상을 하나의 공식 기록으로 남길 수 있지만,  
각 참가자가 자신의 장면을 다시 찾아  
개인 콘텐츠로 만드는 것은 쉽지 않습니다.

HILiT은  
**대회 영상 → 참가자별 하이라이트 → 개인 공유 → 대회 노출 확산**의 구조로 확장할 수 있습니다.

### 대회 주최자에게 생기는 가치

- 참가자별 개인 하이라이트 제공
- 경기 결과뿐 아니라 참여 경험 자체를 기록
- 참가자가 직접 공유할 이유 제공
- 하나의 경기에서 다수의 콘텐츠 생산
- 참가자 채널을 통한 대회명/브랜드 노출 확대
- 다음 대회 모집에 활용할 콘텐츠 확보
- 팀·참가자와의 지속적인 접점 형성
- 대회 기록 서비스로의 확장 가능성

### Tournament Promotion Loop

`대회 개최`

→ `경기 영상 생성`

→ `참가자별 개인 하이라이트`

→ `각 참가자의 기록/공유`

→ `대회 콘텐츠의 다중 확산`

→ `대회·주최 브랜드 발견`

→ `차기 참가 관심`

‘홍보 효과’를 아래처럼 **확정적인 성과**로 표현하지 않습니다.

- “회원이 반드시 늘어납니다” X
- “매출이 증가합니다” X
- “SNS 조회수가 N배 증가합니다” X

- `홍보 콘텐츠로 활용할 수 있습니다`
- `노출 접점을 늘리는 구조를 만듭니다`
- `신규 멤버/고객/참가자 유입으로 연결되는지 검증합니다`

처럼 표현합니다.

## Q1. 제 영상이 서버로 올라가나요?

기본적으로는 기기 내 처리를 우선합니다.

현재 서비스 설계에서는  
추적이 흔들려 기기에서 회복하기 어려운 일부 구간 등  
서버 처리가 필요한 경우에만 필요한 데이터를 보내는 방식을 고려합니다.

개인용 Cloud Boost 등 서버 기반 기능을 사용하는 경우에는  
해당 처리 범위에 맞는 서버 처리가 발생합니다.

> 실제 공개 시점의 처리 정책, 보관 기간, 삭제 정책을 기준으로 최종 문구를 확정합니다.

## Q2. AI 에이전트는 무엇을 하나요?

AI 에이전트는 단순히 인물을 추적하는 기능을 넘어  
하이라이트 영상을 만드는 과정을 하나의 흐름으로 연결하는 역할을 지향합니다.

사용자가 원하는 사람을 선택하면:

- 인물 추적
- 본인 중심 후보 장면 탐색
- 핵심 장면 정리
- 세로형 콘텐츠 구성
- 하이라이트 숏폼 제작

까지 연결하는 방향입니다.

> 자동 캡션, 썸네일, 음악 등 실제 제공 기능은 출시 범위에 맞춰 표기합니다.

개인 기록으로 남길 수 있습니다.

다만 `나만 보기`로 설정한 기록은  
공유할 수 없도록 공개 범위를 우선합니다.

현재처럼 영상 파일 자체가 외부로 나가는 방식이 아니라  
HILiT 기록 링크를 공유하는 구조라면
